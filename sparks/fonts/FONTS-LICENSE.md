# Bundled fonts

Both fonts are subsets of the official variable fonts, licensed under the
SIL Open Font License 1.1 (https://openfontlicense.org).

- Noto Sans Arabic — Copyright The Noto Project Authors (https://github.com/notofonts/arabic)
- Nunito — Copyright The Nunito Project Authors (https://github.com/googlefonts/nunito)

Subsets were produced with fontTools (`pyftsubset`) and kept as WOFF with all
OpenType layout features so Arabic joining and shaping work fully offline.
